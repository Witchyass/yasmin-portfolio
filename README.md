# Yasmin Sebei - Portfolio

An interactive portfolio website built with Next.js.

## Features

- 🎨 Modern, responsive design
- ⚡ Fast and optimized with Next.js 14

## Tech Stack

- Next.js 14
- React
- TailwindCSS
- Framer Motion
- Deployed on Vercel

## Getting Started

### Prerequisites
- Node.js 18+
- pnpm or npm

### Setup

1. Clone the repository
```bash
git clone <your-repo-url>
cd yasmin-portfolio
```

2. Install dependencies
```bash
pnpm install
```

3. Run development server
```bash
pnpm dev
```

Visit `http://localhost:3000`

## Deploy on Vercel

1. Push to GitHub
2. Import repository in Vercel
3. Deploy!

## Customize

Edit `lib/portfolio-data.ts` to update your information:
- Personal details
- Skills and technologies
- Projects
- Experience
- Awards
